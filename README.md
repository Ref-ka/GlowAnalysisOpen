# GlowAnalysis

На данный момент я переделываю всю систему для полноценной работы, до этого просто была гора наработок. <br />

### Описание директорий
* images - все обработанные и необработанные изображения
* inference - скрипты для полноценной работы системы и её отдельных частей
* labels - файлы с готовыми лейблами и скрипты для работы с этими файлами
* process - скрипты для обработки изображений и видео
* train - скрипты для обучения моделей
* trained_models - обученные модели в формате *.pth
* videos - все обработанные и необработанные видео

На данный момент нет нормального описания пайплайна подготовки и работы системы, <br />также нет описания работы каждой из частей системы ввиду нехватки времени.
